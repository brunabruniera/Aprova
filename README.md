## Sobre o projeto

O **Aprova** é um site criado para ajudar estudantes a organizar seus estudos de forma simples, prática e fácil de entender. A ideia é reunir conteúdos escolares em um só lugar para facilitar a aprendizagem.

## O que você encontra no Aprova

| Seção | Descrição |
|-------|-----------|
| **Início** | Página inicial com a apresentação do projeto e das seções do site. |
| **Matérias** | Conteúdos de diferentes matérias escolares, organizados de forma simples. |
| **Ano de Ensino** | Escolha seu ano de ensino e encontre conteúdos de acordo com seu nível escolar. |
| **Quiz** | Perguntas para testar seus conhecimentos e descobrir o quanto você aprendeu. |
| **Resumos** | Revisão rápida dos principais conteúdos antes das provas. |

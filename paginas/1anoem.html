1º Ano do Ensino Médio

Conteúdos, métodos de estudo e dicas para se preparar para as provas.

Dicas para se preparar para as provas

Crie uma rotina

Separe um horário para cada matéria e evite deixar o estudo para a última hora.

Faça resumos

Organize os conceitos principais usando palavras-chave, tópicos e exemplos.

Pratique questões

Resolva exercícios e provas anteriores para entender como os conteúdos são cobrados.

Revise seus erros

Anote as questões que errou e descubra o motivo antes de tentar novamente.

Conteúdos do 1º Ano

01

Português

Principais conteúdos

Interpretação de textos, gêneros textuais, literatura, funções da linguagem, gramática, sintaxe e figuras de linguagem.

Como estudar

Leia textos, faça anotações e pratique interpretação e análise gramatical.

Método

Leia → identifique → resuma → pratique → revise.

02

Matemática

Principais conteúdos

Conjuntos, funções, equações, inequações, razão, proporção, porcentagem, geometria e trigonometria básica.

Como estudar

Entenda a regra ou fórmula, observe exemplos e resolva exercícios progressivamente.

Método

Teoria → exemplo → exercício fácil → exercício difícil → correção.

03

Física

Principais conteúdos

Grandezas físicas, movimento, velocidade, aceleração, gráficos, força e leis de Newton.

Como estudar

Entenda o significado das fórmulas e pratique cálculos com diferentes situações.

Método

Conceito → fórmula → unidades → exemplo → exercícios.

04

Química

Principais conteúdos

Matéria, propriedades, modelos atômicos, elementos químicos, tabela periódica, ligações químicas e substâncias.

Como estudar

Monte tabelas e esquemas para relacionar conceitos e características.

Método

Conceito → exemplo → tabela → exercícios → revisão.

05

Biologia

Principais conteúdos

Características dos seres vivos, células, organização dos seres vivos, metabolismo e classificação biológica.

Como estudar

Use desenhos, esquemas e mapas mentais para memorizar estruturas e processos.

Método

Leia → desenhe → relacione → explique → revise.

06

História

Principais conteúdos

Antiguidade, Idade Média, Renascimento, Reforma Religiosa, expansão marítima e formação do mundo moderno.

Como estudar

Organize os acontecimentos em linhas do tempo e destaque causas e consequências.

Método

Contexto → acontecimento → causa → consequência → revisão.

07

Geografia

Principais conteúdos

Cartografia, espaço geográfico, território, população, clima, relevo, recursos naturais e globalização.

Como estudar

Use mapas, gráficos e imagens para compreender e comparar os conteúdos.

Método

Observe → compare → anote → relacione → revise.

08

Inglês

Principais conteúdos

Simple present, present continuous, simple past, pronomes, verbos, vocabulário e interpretação de textos.

Como estudar

Pratique vocabulário, estruturas gramaticais e leitura de pequenos textos.

Método

Vocabulário → regra → exemplo → leitura → exercícios.

Método de revisão rápida

Revise os conceitos principais, refaça exercícios e tente explicar cada assunto sem consultar o material.
